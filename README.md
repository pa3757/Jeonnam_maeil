# 전남매일 AI 특강 — 기자를 위한 AI 취재·검증

- `slides/전남매일_AI특강_개념슬라이드.pptx` — 개념 설명 슬라이드 34장 (발표자 노트에 발표 스크립트 + 진행 메모)
- `index.html` — 브라우저용 슬라이드 뷰어 (GitHub Pages 배포용)
- `viewer/slides/` — 뷰어용 슬라이드 이미지·썸네일

## GitHub Pages 배포

1. 저장소 **Settings → Pages**
2. **Source**: `Deploy from a branch`
3. **Branch**: 배포할 브랜치 / `/ (root)` 선택 후 Save
4. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 에서 확인

## 뷰어 단축키

| 키 | 동작 |
| --- | --- |
| ← → / Space | 이전·다음 슬라이드 |
| G | 슬라이드 목차 |
| N | 발표자 노트 열기·닫기 |
| F | 전체 화면 |
| Home / End | 처음·끝 |

`#번호`로 특정 슬라이드 링크 가능 (예: `index.html#16`). 모바일은 좌우 스와이프.
